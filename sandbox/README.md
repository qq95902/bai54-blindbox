# BAI 本地链沙盒

在项目根目录运行：

```sh
npm run sandbox:simulate
```

脚本会在本机启动临时 Ganache 链（Chain ID 31337），即时编译项目中的游戏、代币和免费领取合约，部署后按固定随机种子执行场景。模拟链关闭后会清理临时文件；所有账户、余额和合约只存在于这次本地运行中。

目前覆盖：USDT/BNB 买盒、钱包与每日限额、封盘和开奖、VRF 延迟重试与旧请求回调、中奖领奖、未中奖 BAI、直属邀请人每个付费盒 3 USDT 返佣与单次领取、返佣从流动性预算扣除、免费奖励暂存和解锁、卡牌挂卖/取消/购买、合成成功及超时退款、BAI 交易税和分红领取；另外检查 API 限流在直连、可信单层代理、多层代理和伪造转发头时的客户端 IP 解析。运行结果会列出每项断言及通过数量。

VRF、USDT、BNB 报价、流动性处理器和交易对由本地模拟合约替代。后端 HTTP 服务本身尚未连接 PostgreSQL/RPC 做并发压测。沙盒验证游戏合约之间的流程和记账，不代表真实 Chainlink 订阅、DEX 路由、BSC RPC、数据库负载或主网部署已经通过验证。
