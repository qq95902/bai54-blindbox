## English

Static website and bilingual gameplay whitepaper for BAI / 54. The site entry point is `index.html`; the whitepaper is `whitepaper.html`.

GitHub Pages hosts static files only. Blind-box purchases, draws, card synthesis, and marketplace interactions currently run in the browser and do not submit on-chain transactions or represent real USDT, BNB, or BAI assets. The whitepaper describes proposed gameplay and parameters; on-chain asset features are not enabled.

Binance Agentic Wallet pairing requires each visitor's own official CLI and local wallet bridge (default URL: `http://127.0.0.1:8787`). GitHub Pages does not host or expose that bridge. This repository excludes the wallet server, keys, and credentials.

BAI / 54 is an independent concept project and is not affiliated with, sponsored by, or endorsed by Binance.
